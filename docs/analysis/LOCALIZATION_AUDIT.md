## Configuration Overview
The Laravel app configuration declares Lithuanian as the default locale, English as the fallback, and exposes a comma-separated list of `lt,en,ru,de` to drive middleware, hreflang tags, and sitemap generation. It also only maps Lithuanian to a currency/zone pair, leaving other locales without automatic currency alignment.【F:config/app.php†L76-L110】 Shared UI configuration mirrors the default locale but trims the supported list to `lt`, `en`, and `de`, while the feature toggle configuration further narrows the supported locales array to just English and Lithuanian, diverging from the primary list.【F:config/shared.php†L36-L49】【F:config/app-features.php†L55-L75】 The Filament language tabs helper backfills its defaults from either the shared list or the `app` locales, guaranteeing at least the primary language is required.【F:config/filament-language-tabs.php†L1-L27】 Both storefront and admin middleware sanitize locale input against the same configuration set, persist selections, and ensure Filament sessions respect the resolved language.【F:app/Http/Middleware/SetLocale.php†L17-L134】【F:app/Http/Middleware/SetFilamentLocale.php†L17-L39】 Filament's admin panel provider harvests locales from configuration to seed the Spatie translatable plugin so that administrators receive consistent editing tabs across languages.【F:app/Providers/Filament/AdminPanelProvider.php†L54-L99】

## Language Coverage Details
### Lithuanian (lt)
Lithuanian is both the configured default and the locale used when middleware falls back from unsupported input, aligning with the shared localization defaults.【F:config/app.php†L76-L110】【F:config/shared.php†L36-L49】 The primary `lt.php` catalog covers navigation, authentication, checkout, product merchandising, admin widgets, and settings metadata, ensuring comprehensive storefront and admin messaging.【F:resources/lang/lt.php†L5-L120】 Complementary JSON phrases extend coverage to dynamic storefront strings, analytics summaries, and newsletter CTAs.【F:resources/lang/lt.json†L1-L80】

### English (en)
English operates as the fallback locale and is fully represented across keyed and JSON translation stores, mirroring Lithuanian coverage for navigation, checkout flows, analytics, and marketing prompts.【F:config/app.php†L76-L89】【F:resources/lang/en.php†L5-L118】【F:resources/lang/en.json†L1-L80】 English also appears throughout shared configuration arrays, so UI components relying on `config('shared.localization.supported_locales')` retain parity with the default language.【F:config/shared.php†L36-L49】

### German (de)
German is listed in the global supported locales and receives storefront translations via a trimmed PHP dictionary and a more complete nested `store.php` structure for navigation, checkout, and cart copy.【F:config/app.php†L89-L110】【F:resources/lang/de.php†L5-L19】【F:resources/lang/de/store.php†L6-L60】 The JSON catalog broadens German coverage to newsletters, admin statistics, and lookup dialogs, but there are no dedicated admin PHP translation arrays beyond navigation, suggesting limited back-office localization.【F:resources/lang/de.json†L1-L80】 Moreover, shared configuration and system settings expose German while other auxiliary configs (like `app-features`) omit it, which can desynchronize runtime feature toggles from available translations.【F:config/shared.php†L36-L49】【F:config/app-features.php†L55-L75】

### Russian (ru)
Russian is present in the primary supported locale list and has storefront navigation strings plus rich JSON coverage for newsletter forms, sliders, and order lookups, indicating partial storefront enablement.【F:config/app.php†L89-L110】【F:resources/lang/ru.php†L5-L19】【F:resources/lang/ru.json†L1-L72】 The admin `ru.php` catalog focuses on price management screens, leaving other resources untranslated and highlighting a targeted rather than holistic back-office rollout.【F:resources/lang/ru/admin.php†L6-L64】 Unlike German, Russian is absent from shared configuration arrays and from the default-language system setting options, which complicates exposing the locale through UI selectors despite translation assets being available.【F:config/shared.php†L36-L49】【F:database/seeders/SystemSettingsSeeder.php†L220-L236】

## Risks and Recommendations
- **Align locale configuration sources:** Expand `config/shared.php` and `config/app-features.php` to include Russian (and confirm German) so feature toggles, language tabs, and shared view data remain consistent with `config('app.supported_locales')`.【F:config/shared.php†L36-L49】【F:config/app-features.php†L55-L75】
- **Update administrative settings:** Add Russian to the `app.language` system setting options so dashboard dropdowns reflect all supported locales and administrators can select it as a default when needed.【F:database/seeders/SystemSettingsSeeder.php†L220-L236】
- **Broaden locale mapping and admin coverage:** Define currency/timezone mappings for German and Russian (and other future locales) to keep session currency alignment predictable, and prioritize translating remaining admin resources for German and Russian to avoid mixed-language experiences.【F:config/app.php†L89-L110】【F:resources/lang/de.php†L5-L19】【F:resources/lang/ru/admin.php†L6-L64】
- **Document CSP-safe search bindings:** Storefront search and autocomplete widgets now share centralized Alpine factories so Livewire entangled translations stay reactive without inline scripts, maintaining CSP compliance alongside multilingual payloads.【F:resources/js/alpine/search-components.js†L1-L170】【F:resources/views/livewire/components/live-search.blade.php†L24-L41】
