# Change: Add Order Creation Attachments and PDF Generation

## Why
Admin users need to build orders with products and services in one flow and generate all required PDF documents automatically to reduce manual steps.

## What Changes
- Add product and service attachment controls on the order create page.
- Generate all order PDF documents on creation and expose them in the order documents area.

## Impact
- Affected specs: admin-orders
- Affected code: Order create page, order resources, document generation services
