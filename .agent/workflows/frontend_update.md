# Frontend Update Workflow

## 1. Inspect Existing UI
- Review existing Blade components and CSS conventions.
- Identify reusable components.

## 2. Implement UI Changes
- Use Tailwind v4 utilities.
- Use gap utilities for spacing in lists.
- Support dark mode if present.

## 3. Verify
- Ask the user to run npm run dev or npm run build if changes do not appear.
